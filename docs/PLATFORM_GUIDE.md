# 平台模块与使用说明

## 1. 平台定位

AI 反馈教学平台用于《运动技能学习与控制》课堂中的测评、即时反馈和训练追踪。教师可以把课堂任务拆成多个功能模块，学生完成测评后获得反应、平衡、姿态和动作稳定性等指标，再根据反馈进行再练习。

平台的核心闭环是：

```text
选择课堂模块 → 完成测评 → 查看指标与报告 → 接收反馈 → 再练习 → 对比训练记录
```

姿态分析在浏览器端处理摄像头画面，只上传姿态指标、报告和训练记录，不上传原始视频。

## 2. 模块介绍

### 2.1 信息加工

用于体验从刺激出现到动作反应之间的信息加工过程。

- `F1.1 简单反应时`：刺激出现后完成单一反应，观察基本反应速度。
- `F1.2 选择反应时`：根据不同刺激选择对应反应，观察刺激识别、反应选择对速度的影响。

### 2.2 感觉系统与本体感觉

用于观察感觉输入、身体位置觉和姿态控制之间的关系。

- `F2.1 单腿站立平衡测试`：记录单腿站立时的对称性、晃动趋势和稳定时长；可按睁眼/闭眼条件重复。
- `F2.2 重心轨迹可视化`：跟踪肩髋关键点，观察站立过程中的动态平衡变化。
- `F2.3 姿态控制评估`：综合肩、髋、膝、肘等关节点，评估姿态对称性与控制质量。

### 2.3 注意力分配

- `F3.1 单/双任务反应时对比`：比较单任务和双任务条件下的反应表现，用于讨论注意资源、认知负荷和任务干扰。

### 2.4 动作协调与控制

用于把动作过程中的关节变化转化为可观察的运动学指标。

- `F4.1 关节点轨迹分析`：实时识别人体骨架，查看膝、髋、肘等角度以及左右对称性。
- `F4.2 动作稳定性分析`：连续重复同一动作，比较角度波动、姿态一致性和重复动作质量。

姿态功能需要用户主动开启摄像头。建议全身或主要动作关节完整入镜，摄像头距离约 2–3 米，并在开始检测前等待关键点稳定识别。

### 2.5 反馈与运动学习

- `F5.1 动作前后对比`：对照不同练习阶段的动作指标。
- `F5.2 误差反馈`：结合测评结果识别偏差，为下一次练习提供反馈方向。
- `F5.3 再练习效果追踪`：按时间查看重复练习后的变化，形成个人或班级学习曲线。

### 2.6 数据中心

`F6.1 数据中心`面向研究者和教师工作场景。管理员可以按班级、时间、功能编号和实验阶段筛选记录，查看学生、测试条件、结果和指标，并导出 Excel 供后续统计分析。

学生即使获得数据中心权限，也只能看到自己的训练记录；管理员可以查看全量记录。

### 2.7 我的训练档案

`F6.2 我的训练档案`面向学生个人。页面展示本人训练记录、项目数、累计时长、姿态质量、肩髋对称性、采样点和报告下载入口。学生不能自行删除记录；如需处理异常记录，应联系管理员。

## 3. 学生使用流程

1. 打开平台登录页，输入管理员创建的用户名和密码。
2. 首次登录或密码被重置后，按提示进入“修改密码”并设置新密码。
3. 登录后首页只展示管理员授权的模块；直接访问未授权路由会进入无权限页面，接口也会拒绝请求。
4. 进入课堂模块并按页面步骤完成测评。涉及姿态分析时，点击“开启摄像头”并在浏览器提示中允许摄像头权限。
5. 完成检测后查看实时指标和报告。训练指标、报告摘要和必要的姿态采样数据会同步到后端训练档案。
6. 在“我的训练档案”查看历史记录。只有被管理员授予下载权限时，Excel 和报告下载按钮才可用。
7. 使用右上角用户菜单中的“退出登录并切换用户”结束当前会话，再由下一位学生登录。

## 4. 管理员使用流程

### 4.1 用户管理

点击右上角用户菜单中的“用户管理”，可以：

- 创建管理员或学生用户；用户名创建后不可修改；
- 设置显示名、班级、学号和初始密码；留空初始密码时由系统生成临时密码；
- 编辑用户角色和有效/停用状态；
- 给学生逐项授权七个模块，并单独授权下载文件；
- 重置密码；
- 回收用户会话，使其现有登录立即失效。

停用用户、角色变化、密码重置和回收会话都会使相关旧会话失效。管理员不能停用或降级自己，且任何操作都不能导致系统没有有效管理员。

### 4.2 数据中心

进入“数据中心”后，可使用班级、功能编号和实验阶段筛选训练记录。管理员可查看全量数据并导出 Excel；导出接口会再次检查管理员角色和下载权限。

### 4.3 密码与会话

管理员可在用户菜单中进入“修改密码”。如果怀疑账号仍在其他设备登录，可在用户管理中回收会话，再要求用户使用新密码重新登录。

## 5. 权限规则

| 能力 | 管理员 | 学生用户 |
| --- | --- | --- |
| 查看七个教学模块 | 默认全部拥有 | 按用户逐项授权 |
| 数据中心 | 可查看全量记录 | 仅能查看本人记录，且需授权 |
| 我的训练档案 | 可访问管理员可见页面 | 需授权，仅本人数据 |
| 创建/编辑用户 | 可以 | 不可以 |
| 修改角色、停用、重置密码、回收会话 | 可以，但不能处理自己造成零管理员 | 不可以 |
| Excel、报告和文件下载 | 默认允许 | 单独授权 |

权限同时在前端和后端执行：前端隐藏无权限入口，后端对每个受保护接口再次验证登录状态、角色、模块权限和下载权限。无权限接口返回 HTTP `403`。

## 6. 摄像头与隐私要求

- 摄像头只在进入受保护的姿态分析页面并点击“开启摄像头”后启动。
- 公网环境必须使用 HTTPS 安全上下文；本地开发可以使用 `localhost`。如果证书不受浏览器信任，摄像头权限可能仍被拒绝。
- 建议保持光线充足，让全身或主要动作关节完整入镜，检测过程中避免频繁遮挡。
- 平台不保存原始视频，不把视频上传到后端；后端只保存关键点派生指标、报告和训练记录。
- 若浏览器拒绝权限，请检查地址栏摄像头图标、站点权限和系统摄像头占用情况，然后刷新页面重新授权。

## 7. 页面与接口速查

| 页面 | 用途 |
| --- | --- |
| `/login` | 登录；系统不提供 `/register` |
| `/` | 权限过滤后的课程首页 |
| `/platform.html` | 兼容旧版课程教学入口和认证桥接 |
| `/pose-analysis?lesson=F4.1` | 姿态分析与报告生成 |
| `/data-center` | 数据中心 |
| `/training-archive` | 学生训练档案 |
| `/admin/users` | 用户和权限管理 |
| `/change-password` | 修改密码 |

后端接口按用途分为：

- `/api/auth/login`、`/api/auth/logout`、`/api/auth/me`、`/api/auth/change-password`；
- `/api/admin/users` 及其子路径；
- `/api/training-records` 及导出、报告下载路径；
- `/api/data-center` 及导出路径；
- `/api/health` 服务健康检查。

写接口和导出接口使用 HttpOnly、Secure、SameSite Cookie，并要求 `X-CSRF-Token`。登录失效时前端会自动回到登录页。

## 8. 部署后检查

部署完成后建议按以下顺序验收：

1. 访问 HTTPS 地址，未登录时自动进入 `/login`。
2. 使用管理员账号登录并完成首次改密。
3. 创建一个学生账号，确认默认没有模块和下载权限。
4. 逐项授权后确认首页入口、姿态分析页面和下载按钮按权限显示。
5. 直接访问未授权页面或接口，确认页面显示无权限、接口返回 `403`。
6. 在管理员用户管理中测试停用、重置密码和回收会话。
7. 确认管理员不能停用或降级自己，系统始终至少保留一个有效管理员。
8. 在 HTTPS 姿态分析页面手动授予摄像头权限，确认可以开启预览和完成检测。

生产部署、Conda、systemd、Nginx 和数据库目录说明见 [`deploy/README.md`](../deploy/README.md)。
