# AI 反馈教学平台

面向《运动技能学习与控制》课程的课堂辅助平台。平台把反应时、双任务、平衡、姿态、动作稳定性和训练结果转化为可观察的指标，帮助教师进行课堂测评、反馈和过程追踪，帮助学生理解“动作—反馈—再练习”的运动学习过程。

平台包含 React 单页页面、保留的课程教学入口 `platform.html`，以及 FastAPI + SQLite 后端。登录、用户权限、训练记录和文件导出均由后端控制；姿态分析只保存姿态指标、报告和训练记录，不上传原始视频。

## 平台模块

| 模块 | 功能编号 | 课堂用途 |
| --- | --- | --- |
| 信息加工 | F1.1、F1.2 | 简单反应时与选择反应时，观察刺激识别、反应选择和动作反应速度。 |
| 感觉系统与本体感觉 | F2.1、F2.2、F2.3 | 单腿站立平衡、重心轨迹和姿态控制评估，观察感觉输入与姿态调节。 |
| 注意力分配 | F3.1 | 单任务/双任务反应时对比，体验认知负荷和注意资源分配。 |
| 动作协调与控制 | F4.1、F4.2 | 关节点轨迹与动作稳定性分析，比较角度、左右对称性和重复动作一致性。 |
| 反馈与运动学习 | F5.1、F5.2、F5.3 | 动作前后对比、误差反馈和再练习效果追踪，形成学习曲线。 |
| 数据中心 | F6.1 | 按班级、时间、功能和实验阶段筛选训练记录，供教师查看和导出。 |
| 我的训练档案 | F6.2 | 学生查看自己的历史训练指标、姿态报告和累计训练情况。 |

各模块的详细操作步骤、权限规则和常见问题见[平台模块与使用说明](docs/PLATFORM_GUIDE.md)。

## 账号与权限

- 系统不开放自助注册，账号由管理员创建。
- 支持 `管理员` 和 `学生用户` 两种角色。
- 管理员可以创建、编辑、停用用户，修改角色，重置密码和回收会话。
- 学生的模块权限按用户逐项配置，下载文件权限单独控制；未授权模块不会在前端显示，后端接口也会返回 `403`。
- 管理员默认拥有全部七个模块和下载权限，且不能停用或降级自己；系统始终保留至少一个有效管理员。
- 首个管理员用户名固定为 `admin`。初始密码只通过服务器环境变量注入，首次登录必须修改密码，不写入仓库。

## 主要页面与接口

页面入口：

- `/login`：登录页；不提供 `/register`。
- `/`：课程首页，按当前用户权限展示模块。
- `/platform.html`：课程教学平台入口，兼容旧版课程模块和认证桥接。
- `/pose-analysis?lesson=F4.1`：摄像头姿态分析；`lesson` 可使用具体功能编号。
- `/data-center`：数据中心，管理员查看全量记录，学生只查看本人记录。
- `/training-archive`：我的训练档案。
- `/admin/users`：管理员用户与权限管理。
- `/change-password`：修改密码。

认证与数据接口包括 `/api/auth/*`、`/api/admin/users*`、`/api/training-records*` 和 `/api/data-center*`。所有写入和导出请求使用 HttpOnly、Secure、SameSite Cookie，并要求 CSRF Header；后端会再次校验登录状态、角色、模块权限和下载权限。

## 本地开发

前端建议使用 Node.js 20 和 pnpm：

```bash
pnpm install
pnpm dev
```

生产构建、代码检查和测试：

```bash
pnpm build
pnpm lint
pnpm test
```

后端使用独立 Conda 环境：

```bash
conda create -n aift python=3.11 -y
conda activate aift
pip install -r backend/requirements.txt
uvicorn backend.app.main:create_app --factory --host 127.0.0.1 --port 8001
```

开发时可将前端 Vite 代理到本机 API；生产配置示例在 `deploy/` 目录。SQLite 数据库应放在版本目录之外，并由 systemd 管理 FastAPI、由 Nginx 反代 `/api`。

## 摄像头、隐私与数据导出

摄像头只在用户打开具体姿态分析并点击“开启摄像头”后启动。浏览器需要安全上下文：本地开发可使用 `localhost`，公网访问应使用有效的 HTTPS 证书；仅使用普通 HTTP 的公网 IP 页面通常无法获得摄像头权限。

姿态分析在浏览器端读取视频并计算关键点、角度、对称性和质量指标。平台不保存或上传原始视频，只将姿态指标、报告和训练记录保存到后端。数据中心和训练档案的 Excel、报告下载都由后端生成并再次校验下载权限。

## 部署与维护

生产部署说明见 [`deploy/README.md`](deploy/README.md)。发布目录使用版本目录和 `current` 符号链接，切换版本时不覆盖数据库。上线后至少检查：

1. `systemctl is-active ai-feedback-teaching-platform` 为 `active`；
2. `GET /api/health` 返回 `{"status":"ok"}`；
3. HTTP 入口跳转 HTTPS；
4. 未登录访问受保护页面会进入登录页；
5. 学生权限、下载权限和数据隔离符合管理员配置。
